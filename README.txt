# RotiYa — prototipo funcional

Abrí `index.html` en un navegador para probarlo.

Incluye:
- Tienda responsive inspirada en las pantallas diseñadas.
- Logo proporcionado.
- Tarjetas de comida con efecto 3D al mover el cursor.
- Ofertas del día.
- Carrito visual con contador.
- Búsqueda y filtros por categoría.
- Panel administrador con pedidos, métricas y ventas.
- Sidebar del administrador sin “Clientes” y sin los bloques promocionales que pediste quitar.

Nota: es un prototipo frontend. Para producción habría que conectar backend/base de datos, autenticación, pagos y gestión real de pedidos.
